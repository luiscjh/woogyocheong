  변경: member → small_leader → mid_leader → executive → admin 5단계

  추가된 상수:
    - UserRole.smallLeader  : 소팀장
    - UserRole.midLeader    : 중팀장
    - UserRole.executive    : 임원팀
    - UserRole.labels       : 역할 한글 레이블 맵

    - AppTeams.midTeams     : ['A', 'B', 'C', 'D']
    - AppTeams.smallTeams   : 'A-1' ~ 'D-4' (16개 소팀)
    - AppTeams.smallTeamsOf : 특정 중팀의 소팀 목록 반환 헬퍼

■ 역할 양도(인계) 기능 추가
  - 배경: 소팀장/중팀장/임원팀이 교체될 때마다 관리자가 매번 권한을
    새로 부여해야 하는 비효율 해소
  - lib/services/firestore_service.dart: transferRole(outgoing, incoming)
    추가 — 후임자에게 역할+보유 추가권한(예: 심방확정권한)을 넘기고,
    기존 보유자는 role='member', permissions=[] 로 전환
  - lib/providers/auth_provider.dart: setCurrentUser() 추가 — 본인이
    스스로 역할을 양도한 직후, 재로그인 없이 세션에 즉시 반영
  - lib/screens/profile/profile_screen.dart: '내 정보' 화면에 역할 배지
    표시 추가 + '{역할} 역할 양도' 버튼 추가
      · 소팀장 → 같은 소팀의 '팀원'에게만 양도 가능
      · 중팀장 → 같은 중팀의 '팀원'에게만 양도 가능
      · 임원팀 → 전체 '팀원' 중 아무에게나 양도 가능
      · 대상은 항상 role == member인 사람만 후보로 노출 (다른 리더 역할을
        실수로 덮어쓰지 않도록)
  - 브라우저 자동화로 소팀장(정소팀) → 팀원(이청년) 양도 전체 플로우 검증
    완료 (후보 목록 필터링, 확인 다이얼로그, 양도 후 즉시 배지/버튼 소멸,
    관리자 화면에서 실제 역할 변경 반영까지 확인)
