테스트유저 (testing@church.com)
  - 초기 역할은 '관리자'로 시작하지만, '내 정보' 화면에 이 계정에서만
    보이는 '테스트 계정 - 역할 전환' 드롭다운으로 즉시 전환 가능
    (lib/screens/profile/profile_screen.dart _TestRoleSwitcherSection,
    이메일이 testing@church.com일 때만 노출)
  - 선택지: 팀원 / 소팀장 / 중팀장 / 임원팀 / 목사님 / 관리자 /
    새가족 / 새가족팀 리더 / 새가족팀 팀장 / 콘텐츠팀 팀원 /
    콘텐츠팀 팀장 (11종) — 새가족 관련 항목은 role+department를 한
    쌍으로 전환. 콘텐츠팀 항목은 department는 그대로(A-1) 둔 채
    ministryTeam(사역팀 소속, department와 독립된 축)만 부여함
    (콘텐츠팀 팀장은 role=팀원 + ministryTeam=콘텐츠팀 + 팀장 플래그)
  - 다른 계정으로 로그인/로그아웃 반복할 필요 없이 한 계정으로 전체
    권한 레벨을 테스트하기 위한 용도

오새가족 (newfamily@church.com) - 새가족팀장
  - 새가족팀은 중팀/소팀과 독립적으로 운영되는 팀. 새가족팀장은 role이
    'mid_leader'이지만 department가 '새가족팀'이라 중팀 A~D와는 무관하게
    새가족팀 전체만 조회/관리 (중팀장과 동일한 권한 수준)
  - 관리 메뉴에 '새가족 관리'(소팀 배정 포함)와 '새가족 로테이션 관리'
    화면이 노출됨 (모두 새가족팀장 전용, 리더에게는 없음)
  - 새가족 로테이션 관리: 특정 날짜가 아니라 새가족 온보딩 1~3주차
    (새가족 개개인의 출석 횟수 기준 진행 단계) 각각에 담당 리더를 고정
    배정. 각 주차 카드에는 현재 그 주차에 해당하는 새가족 명단이 실시간
    으로 매칭되어 표시됨
  - 데모 배정: 1주차=윤리더, 2주차=장리더, 3주차=미배정(빈 상태 확인용)

장리더/윤리더 (leader1@church.com, leader2@church.com) - 새가족팀 리더
  - role은 'small_leader'이지만 department가 '새가족팀'이라 소팀
    A-1~D-4와는 무관하게 새가족팀 전체만 조회/수정 가능 (소팀장과 동일한
    권한 수준)
  - '새가족 관리'(소팀 배정) 화면 접근 권한 없음 — 해당 권한은 새가족
    팀장에게만 있음
  - 관리 탭의 '회원 관리'는 팀 전체 명단 대신, 본인이 배정된 주차에
    현재 해당하는 새가족만 읽기 전용으로 보여주도록 대체됨
  - 홈 화면: 본인이 배정된 주차에 현재 해당하는 새가족이 있을 때만
    인사말 옆에 'N주차 담당' 배지가 표시됨 (해당 사항 없으면 배지 없음)

김콘텐츠 (content@church.com) - 콘텐츠팀 팀장 (사역팀)
  - 콘텐츠팀은 지금까지의 중팀/소팀/임원팀/새가족팀과 달리 '사역팀'
    구분이며, UserModel.ministryTeam(department와 완전히 독립된 축)으로
    관리됨. department는 'A-1' 그대로 유지한 채 ministryTeam='콘텐츠팀',
    isMinistryLead=true만 추가로 부여된 상태
  - 사역팀에는 소팀장·일반 팀원만 소속될 수 있음(AppTeams.
    canJoinMinistryTeam) — 임원팀/중팀장/(향후) 다른 사역팀장은 이미
    하나의 팀을 이끄는 역할이라 사역팀 팀원으로 소속될 수 없도록
    회원 관리 화면에서 role 선택에 따라 사역팀 선택란이 비활성화됨
  - 콘텐츠팀 팀장은 회원 정보 수정 권한이 없음(이메일·소속팀 변경 등은
    관리자·임원팀만 가능) — 대신 관리 탭에 '회원 조회' 카드가 노출되어
    콘텐츠팀 소속 인원 명단을 읽기 전용으로 확인만 가능함(수정/추가
    버튼 없음). 단, 본인이 아닌 팀원 각각에는 '제거' 버튼이 있어 콘텐츠팀
    소속만 해제할 수 있음(이메일·소속팀 등 다른 정보는 그대로 유지되고
    ministryTeam/사역팀장/배너 권한 공유만 초기화됨). 콘텐츠팀 소속 배정
    (ministryTeam 부여) 및 사역팀장 지정은 관리자·임원팀의 '회원 관리'
    화면에서만 가능
    (lib/screens/admin/admin_dashboard.dart,
    lib/screens/admin/member_management.dart readOnly 모드)
  - 콘텐츠팀 팀장은 '소팀장 현황'·'회비 관리'는 제외되고, '회원 조회'
    (읽기 전용)·'회의 일정 관리'·'배너 관리'가 노출됨
  - '출석 관리' 대신 '회의 일정 관리'가 노출됨: 일자·회의 주제·논의
    내용·회의 내용 정리를 한 화면(다이얼로그)에서 함께 입력/수정하는
    회의 기록 CRUD 화면 (lib/screens/admin/ministry_meeting_screen.dart,
    lib/models/ministry_meeting_model.dart)
  - '배너 관리'는 콘텐츠팀 팀장의 고유 권한(UserModel.isMinistryLead
    보유자는 자동으로 canManageBanners=true). 팀장 지정(사역팀장 여부)
    자체는 관리자만 변경 가능 (lib/providers/auth_provider.dart
    canManageBanners/canShareBannerAccess)
  - 콘텐츠팀 팀장은 회원 관리 화면 접근 권한이 없으므로, 본인 팀원에게
    배너 관리 권한을 위임(공유)할 때는 배너 관리 화면 우측 상단의
    '권한 공유 대상 지정' 버튼을 사용함 (관리자도 동일 버튼 사용 가능)
    (lib/screens/admin/banner_management.dart _BannerAccessShareDialog)
  - 콘텐츠팀 팀원(팀장이 아닌 소속자)은 기본적으로 '회의 일정'(조회
    전용, FAB 없음·탭하면 읽기 전용 상세 다이얼로그)만 노출됨.
    '배너 관리'는 UserModel.bannerAccessGranted가 true인 팀원에게만
    추가로 노출됨
    (lib/screens/admin/ministry_meeting_screen.dart readOnly 모드)

이콘텐츠 (content2@church.com) - 콘텐츠팀 팀원 (팀장이 아닌 일반 소속자)
  - department는 실제 소속 소팀인 'D-4' 그대로 유지한 채 ministryTeam=
    콘텐츠팀만 추가로 부여됨 (department와 ministryTeam은 독립된 축)
  - 관리 탭에는 '회의 일정'(조회 전용)만 기본 노출되고, '배너 관리'는
    bannerAccessGranted=false(기본값)라 노출되지 않음 — 김콘텐츠(팀장)가
    회원 관리 또는 배너 관리 화면에서 권한을 공유해줘야 노출됨
  - 김콘텐츠 없이도 '콘텐츠팀 팀원(팀장 아님)' 상태를 바로 확인할 수
    있는 고정 데모 계정 (테스트유저의 역할 전환 없이도 검증 가능)

  - UserModel.birthDate(생년월일)/cohort(기수) 필드로 관리. 생년월일은
    기록용이고, 실제 이용 제한은 cohort(기수)만 기준으로 판단함
  - 관리자(관리 탭 '기수 제한 설정' → lib/screens/admin/
    cohort_settings_screen.dart)가 허용 기수 범위(최소~최대)를 직접
    입력해 AppSettingsModel(minAllowedCohort, maxAllowedCohort)로 저장.
    데모 기본값은 11기~20기 (lib/models/app_settings_model.dart)
  - 허용 범위를 벗어난 회원은 로그인은 되지만 출석 체크·회비 납부·
    심방 신청 등 쓰기 동작이 막히고 조회만 가능함(각 화면에 경고 문구
    표시, 심방 탭은 '심방 신청' FAB 자체가 숨겨짐). 목사님 역할은 이
    제한에서 완전히 제외됨 (AuthProvider.isCohortRestricted)
  - cohort가 아직 등록되지 않은(null) 회원은 안전하게 제한 대상에서
    제외됨 — 대부분의 기존 데모 계정은 cohort 미설정 상태
  - 회원 정보 수정(생년월일/기수 포함)은 관리자·임원팀만 회원 관리
    화면에서 설정 가능 (lib/screens/admin/member_management.dart)
  - Google 최초 가입 온보딩 화면에서도 이름/팀과 함께 생년월일·기수를
    필수로 입력받음 (lib/screens/auth/onboarding_screen.dart)
  - 데모 시연용 기수 배정: 이청년=19기(허용 범위 안, 정상 이용),
    박믿음=5기(허용 범위 밖, 조회 전용 제한 데모)
